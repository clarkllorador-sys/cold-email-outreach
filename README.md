# Cold Email Outreach Pipeline

A 4-step automated pipeline that scrapes business leads, generates personalised video emails, and sends them at scale. Built for a UK-based digital marketing agency.

**The full sequence:**  
scrape leads → generate personalised audio → composite personalised video → send email

---

## How it works

### Step 1 — Extract leads (`extract_leads.py`)
Scrapes business listings from OpenTable UK across 46 configurable cities using Playwright + [Bright Data CLI](https://github.com/luminati-io/brightdata-cli) (to bypass Akamai bot protection). For each listing it:
- Fetches the OpenTable detail page and parses the `__INITIAL_STATE__` JSON blob for website, phone, address, and location count
- Visits the business website with Playwright stealth mode to extract contact emails and Instagram profile URL
- Deduplicates and writes all contacts to a Google Sheets CRM tab

### Step 2 — Generate personalised audio (`generate_audio.py`)
For each lead, generates a personalised "Hey [Business Name]" audio clip using ElevenLabs TTS with a cloned voice. Then:
- Adjusts TTS speed dynamically based on syllable count (short names: 1.0×, long: 0.88×)
- Verifies pronunciation with Whisper STT — rejects if transcription doesn't match
- Uploads the verified MP3 to Google Drive and writes the URL back to the sheet

### Step 3 — Generate personalised videos (`generate_videos.py`)
For each verified audio lead, composites a personalised video:
1. Downloads the host's Loom headshot recording (green screen background)
2. Takes a Playwright screenshot of the lead's website
3. FFmpeg chroma-keys the green screen and overlays the host as a PiP in the bottom-left corner (25% of frame width)
4. Splices the personalised name audio onto the front of the host's template audio
5. Uploads the final MP4 + thumbnail to Google Drive

### Step 4 — Send emails (`send_emails_multi_acct.py` or `send_emails.py`)
Sends personalised cold emails with the video thumbnail embedded. Reads from the sheet, round-robins across up to 3 SMTP sender accounts (domain warm-up), and marks rows as sent.

## Architecture

```
cold-email-outreach/
├── extract_leads.py            ← Step 1: Playwright + Bright Data scraper
├── generate_audio.py           ← Step 2: ElevenLabs TTS + Whisper STT
├── generate_videos.py          ← Step 3: Loom + FFmpeg compositor
├── send_emails.py              ← Step 4a: Gmail API (single account)
├── send_emails_multi_acct.py   ← Step 4b: SMTP multi-account (recommended)
├── generate_dummy_leads.py     ← Dev utility: sample leads CSV
└── inputs/
    └── sample_leads.csv        ← Generated by generate_dummy_leads.py
```

Google Sheets acts as the CRM throughout — each step reads from and writes back to the same `contacts` tab.

## Tech stack

| Layer | Choice |
|-------|--------|
| Lead scraping | Playwright + `playwright-stealth` + Bright Data CLI |
| Bot protection bypass | Bright Data residential proxies (`bdata scrape`) |
| Audio generation | ElevenLabs TTS (eleven_multilingual_v2) |
| Audio verification | OpenAI Whisper (local, base model) |
| Video compositing | FFmpeg — chroma key + PiP overlay |
| Video hosting | Google Drive API (OAuth, not service account — avoids quota limits) |
| CRM | Google Sheets (gspread + service account) |
| Email sending | SMTP SSL port 465 / Gmail API |

## Quick start (test mode)

```bash
# 1. Install dependencies
pip install playwright playwright-stealth requests beautifulsoup4 \
    gspread google-auth google-api-python-client openai-whisper \
    python-dotenv elevenlabs

# 2. Install Playwright browsers
playwright install chromium

# 3. Install Bright Data CLI (required for Step 1 and Step 3)
sudo npm install -g @brightdata/cli && bdata login

# 4. Generate sample leads for testing
python generate_dummy_leads.py
# → inputs/sample_leads.csv  (import into Google Sheets)

# 5. Dry-run a single step
python extract_leads.py --no-gsheets --limit 3 --cities London
python generate_audio.py --dry-run
python generate_videos.py --dry-run
python send_emails_multi_acct.py --dry-run
```

## Production setup

1. Copy `.env.example` to `.env` and fill in all credentials
2. Set up Google Sheets: share the spreadsheet with your service account email
3. Upload your headshot recording (green screen) to Loom, named `TEMPLATE`
4. Upload your template audio ("I'm Alex...") to Google Drive — set `TEMPLATE_DRIVE_FILE_ID` in `.env`
5. Run the full pipeline:
   ```bash
   python extract_leads.py --cities London Birmingham Manchester
   python generate_audio.py
   python generate_videos.py
   python send_emails_multi_acct.py --limit 15
   ```

## Key implementation notes

**Bright Data for OpenTable** — OpenTable UK uses Akamai bot protection which blocks headless Playwright. The solution: Playwright loads the search/listing pages (no bot protection), then `bdata scrape` fetches each detail page through Bright Data's residential proxy network, which bypasses Akamai cleanly.

**`__INITIAL_STATE__` JSON blob** — OpenTable embeds all restaurant data in a `<script id="primary-window-vars">` tag as a JSON blob. Parsing this directly is far more reliable than CSS selectors, which break on markup changes.

**Whisper STT verification** — ElevenLabs occasionally mispronounces unusual business names. Whisper transcribes the generated audio and `names_match()` uses normalisation + difflib ratio ≥ 0.75 to confirm the name was said correctly before marking `audio_verified=TRUE`.

**FFmpeg pipeline** — Three-input composite: `(1)` name MP3 (ElevenLabs), `(2)` Loom headshot video, `(3)` host template audio. `loudnorm` filter balances volume between TTS and recorded audio. `-shortest` stops encoding when the Loom video ends.

**Drive OAuth vs service account** — Google Drive has a 15 GB upload quota per service account. Using OAuth credentials (same token as Gmail) avoids this limit entirely.

**SMTP warm-up** — Daily limit defaults to 15 emails across 3 sender accounts (5 each) to avoid spam classification during domain warm-up. Round-robin assignment keeps each account's volume low.
